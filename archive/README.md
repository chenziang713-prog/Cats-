# Archive

This directory stores old project code that was kept for reference while the
current strategy and flow layers are prepared for rewrite.

## old_code

- `run_prototype.py`: early compatibility wrapper for the prototype CLI.
- `tools_self_test.py`: early prototype self-test script that depended on
  `run_prototype.py`.

These files are backups only. They are not part of the current core strategy
runner, output cleanup, template matching, or v2 screen-state debugging path.
